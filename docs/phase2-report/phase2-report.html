事件聚合规则

  • 扫描 frame_analysis.status='done' 帧
  • 相邻 ≤10s 且 event_type 相同 → 合并
  • 置信度均值 < 0.75 → review_status='reviewing'
  • 最终 Video.process_status → 'indexed'

frame_analysis → semantic_events 时间轴示意

灰点 = event_type='normal'（被跳过）。彩色帧按相邻 ≤10s 合并，左下事件因均值 0.72 进入复核。

关键落地 ③ — 向量 + 关键词混合检索

sentence-transformers 可选 + hash-ngram 降级，叠加关键词分数重排；离线也能跑。

一次真实查询的命中过程

POST /api/search — "找一下白色车违停"
→ query = "找一下白色车违停" → q_vec = encode_text(query) # 384-d L2-normalised 候选 6 个事件，逐个打分： ┌─────────────────────────┬──────┬──────┬──────┐ │ event │ vec │ kw │ final│ ├─────────────────────────┼──────┼──────┼──────┤ │ 违停 · 白色轿车 │ 0.81 │ 0.92 │ 0.85 │ ← top1 │ 违停 · 占道 │ 0.74 │ 0.68 │ 0.72 │ │ 疑似剐蹭事件 │ 0.42 │ 0.16 │ 0.32 │ │ 道路障碍 · 围挡 │ 0.39 │ 0.08 │ 0.27 │ │ 行人横穿急刹 │ 0.21 │ 0.00 │ 0.13 │ filtered │ 异常停车 · 鸣笛 │ 0.18 │ 0.04 │ 0.12 │ filtered └─────────────────────────┴──────┴──────┴──────┘ ← 返回 top1 + top2，total elapsed = 28 ms ← 写入 search_queries(qry-9d2e..) + 2 行 search_results

评分公式与降级策略

hybrid_search.py
final = 0.6 * cos(q_vec, ev_vec) + 0.4 * keyword_score(query, event) # 启用真 embedding 时： # paraphrase-multilingual-MiniLM-L12-v2 (384d) # 未启用时（默认）： # 字符 1/2-gram → hash → 384-d → L2 归一 阈值: final ≥ 0.15 才命中 排序: final 降序，写 rank_no 留痕: 每次查询落 search_queries 表 命中事件落 search_results 表 含 answer_text="在 02:03-02:25 命中违停场景"

关键词词典（5 类事件别名）

  • scratch ← 剐蹭 / 刮蹭 / 碰撞 / 擦碰
  • illegal_parking ← 违停 / 停车 / 占道
  • road_obstacle ← 障碍 / 施工 / 围挡 / 路障
  • abnormal_stop ← 急停 / 急刹 / 鸣笛
  • pedestrian_risk ← 行人 / 横穿 / 鬼探头

诚实清单 — 这周没做完的部分

下周阶段汇报时主动说明，避免老师追问时被动。

技术性未实现

  • 真多模态模型调用：演示走 mock；接 DeepSeek/千问只需填 .env 中的 KEY
  • pgvector / PostgreSQL：用 SQLite + 内存余弦等价替代
  • sentence-transformers 真 embedding：默认未装，hash-ngram 兜底
  • HLS 点播 / 异步任务队列：当前同步 FileResponse，长视频会阻塞
  • PDF 摘要：导出包里目前是 Markdown + JSON

已知风险

  • Mock 模型输出有随机性，演示前建议先固定一段视频跑一次
  • 长视频首次 process 偏慢，建议演示用 30–90s 素材

辅助页面未接

  • 告警管理中心：静态展示，未接 audit_logs
  • 全天业务报告 / 模型与安全配置：仍是阶段一的页面雏形
  • 权限管理 UI：后端 users.role 字段就绪，前端编辑界面未做
  • 复核中心：API 已支持 review_status 改写，但页面未把它接上
