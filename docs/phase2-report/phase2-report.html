关键落地 ② — 模型适配器 + 事件聚合

两阶段策略：先逐帧分析、再滑窗合并。模型层是适配器，演示用 mock，真模型只需改 .env。

聚合后的事件在桌面端的显示效果

聚合规则：扫描 status='done' 帧 → 相邻 ≤10s 同类型合并 → confidence 均值 < 0.75 进 reviewing → Video.process_status='indexed'。截图展示选中违停事件后 VLC seek 11:56 + 时间轴高亮 + 详情联动。
  • 扫描 frame_analysis.status='done' 帧
  • 相邻 ≤10s 且 event_type 相同 → 合并
  • 置信度均值 < 0.75 → review_status='reviewing'
  • 最终 Video.process_status → 'indexed'

frame_analysis → semantic_events 时间轴示意

灰点 = event_type='normal'（被跳过）。彩色帧按相邻 ≤10s 合并，左下事件因均值 0.72 进入复核。

真实检索结果列表（桌面端）

默认查询返回 3 条命中：剐蹭 88% · 违停 82% · 围挡 79%，每条带置信度色块、时间区间和 hashtag 标签。

评分公式与降级策略

hybrid_search.py
final = 0.6 * cos(q_vec, ev_vec) + 0.4 * keyword_score(q, ev) # vec: paraphrase-multilingual-MiniLM (384d) # or hash-ngram fallback (no model needed) 阈值 ≥ 0.15；排序 final↓；写 search_queries/results 表

关键词词典（5 类事件别名）

  • scratch ← 剐蹭 / 刮蹭 / 碰撞 / 擦碰
  • illegal_parking ← 违停 / 停车 / 占道
  • road_obstacle ← 障碍 / 施工 / 围挡 / 路障
  • abnormal_stop ← 急停 / 急刹 / 鸣笛
  • pedestrian_risk ← 行人 / 横穿 / 鬼探头
PG 模式：cosine_similarity() 在库内运算
SQLite 模式：numpy Python 余弦降级

辅助页面：UI 已成型，后端数据未接

  • 告警 / 事故 / 复核：KPI + 状态色块 + 表格 + 滚动已就绪，仍是 mock 静态数据
  • 概览页：QPainter 自绘柱状图 + 环形饼图，数据写死待接 /dashboard API
  • 权限管理：矩阵 UI 完成，后端 users.role 就绪，前端编辑功能标记"开发中"
  • ✅ 所有页面可纵向滚动（QScrollArea），内容不再被截断
  • ✅ 所有未接后端的按钮点击弹"功能开发中"提示，不再静默无响应
