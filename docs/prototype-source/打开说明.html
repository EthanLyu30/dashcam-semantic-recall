使用说明

如何查看这个提交版原型

  • 推荐先打开 原型总览.html，从总览页进入各个功能页面。
  • 如果需要直接展示核心界面，可打开 系统状态概览.html。
  • 如果老师想快速浏览页面结构，可打开 plugins/sitemap/sitemap.html。

本次整理内容

  • 新增统一入口页、说明页和页面清单。
  • 页面文件统一改为中文命名，更接近老师附件展示方式。
  • 外部脚本与网络图片已替换为本地资源，离线也能查看。
  • 补充了 `data`、`plugins`、`resources` 等目录，让整体提交结构更完整。

建议提交内容

  • 直接提交整个 `SRS桌面端交互原型_提交版` 文件夹。
  • 不要只单独提交某一个 HTML 页面，否则站点地图和本地资源会丢失。
