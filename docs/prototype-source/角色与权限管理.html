角色与权限管理

U

车主 / 驾驶员

OWNER / DRIVER

仅可查看及检索与其驾驶证/行驶证绑定的车辆视频。具备完整的个人证据链导出权限。

  • 视频回放与检索
  • 个人证据导出
  • 跨车辆检索
  • 模型参数配置
M

车队管理员

FLEET MANAGER

可管理指定车队下的所有车辆及视频资源。具备批量的违章排查、效率分析及证据上报功能。

  • 全车队视频检索
  • 事件报告生成
  • 人工复核任务
  • 核心密钥管理
I

交通巡查员

TRAFFIC INSPECTOR

具备跨平台视频检索权限。主要用于事故复盘及违章证据收集。受系统审计日志监控。

  • 全库跨域语义检索
  • 原始视频无损取证
  • 事故责任报告签注
  • 数据隐私脱敏审核
